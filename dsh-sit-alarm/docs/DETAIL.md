# 久坐提醒

坐 40 分钟、起来活动 5 分钟。计时在 DSH 宿主进程里跑，页面刷新、切换会话都不丢；到点弹 Windows 吐司，面板自动展开提示。轮次统计按本地日期跨天保存。

## 一轮的流程

| 时刻 | 发生什么 |
|---|---|
| 点「开始 40 分钟」 | 进入专注，面板显示倒计时 |
| 第 37 分钟 | 吐司提醒「快结束了，准备站起来」，面板自动展开并变色 |
| 第 40 分钟 | 自动进入 5 分钟休息，吐司提示站起来活动 |
| 第 44 分钟 | 吐司预告「休息快结束了」，面板切到提醒色 |
| 第 45 分钟 | 休息结束，吐司提示「休息达标」；**不自动开始下一轮**，面板停在「开始下一轮」等你点 |

休息超过 5 分钟完全没问题：面板会一直停在「休息达标」，你想休 15 分钟就休 15 分钟，回来点一下才开始下一轮。

## 面板

卡片在**左侧边栏底部**、用户名那一行上方（`sidebar.footer.action` 槽），和工作区不抢地方，侧栏多宽它就多宽。

- 专注中：暂停 / 结束；底部一行今天统计：`今日 N 轮 · 专注 M 分`
- 暂停中：继续 / 结束
- 休息中：开始下一轮（手动提前结束休息）/ 提前结束休息
- 休息达标 / 未开始：开始下一轮
- 收起（✕）后变成一行摘要：`⏱ 39:55 专注中`，点一下展开
- 侧栏折成 56px rail 时是一个 ⏱ 按钮，点一下把侧栏展开

## 统计

每次一轮专注跑完记一次：轮次 +1、专注秒数累加；休息自然结束再记一次达标，休息秒数照实累加（提前结束只加秒数、不算达标）。

- 文件：`~/.dsh/sit-alarm-stats.json`，按本地日期分桶，保留最近 45 天
- 暂停的时间不计入专注；跨零点的一轮记在结束那天
- 删掉这个文件就是清零

```json
{
  "version": 1,
  "days": {
    "2026-11-15": { "rounds": 3, "focusSeconds": 7200, "breaks": 3, "breakSeconds": 900 }
  }
}
```

## 配置

配置存在 `~/.dsh/sit-alarm.json`，改完保存即生效（宿主监听文件改动，不用重启）：

```json
{
  "workMinutes": 40,
  "warnMinutes": 3,
  "breakMinutes": 5,
  "breakWarnMinutes": 1,
  "sound": true
}
```

| 字段 | 默认 | 说明 |
|---|---|---|
| `workMinutes` | 40 | 一轮专注多少分钟 |
| `warnMinutes` | 3 | 结束前几分钟提醒（0 = 不提醒） |
| `breakMinutes` | 5 | 休息倒计时多少分钟 |
| `breakWarnMinutes` | 1 | 休息结束前几分钟预告（0 = 不预告） |
| `sound` | true | 吐司是否带提示音 |
| `autoStartOnLoad` | false | 只有自测用：插件加载时直接开一轮 |

让智能体改配置，直接说「把专注改成 50 分钟、休息结束前 2 分钟预告」就行，它写这个文件；新值对下一轮生效，正在跑的一轮只调整提醒点。

## 实现

- Host 半侧是状态机：`idle → working → break → breakDone`，`paused` 可以插在 working/break 上。所有时间点存绝对时间戳，用一个 `setTimeout` 睡到下一个事件（提醒点或阶段结束）。
- 浏览器半侧每 2 秒通过 `/api/sit-alarm` 精确路由拉一次状态，用 `endsAt` 在本地插值，秒数是连续的。
- 通知用 PowerShell + WinRT 吐司，AUMID `com.deepseek.dsh`（DSH 开始菜单快捷方式注册的那个）。
- 面板注册在 `sidebar.footer.action` 槽（侧栏 Settings 行上方），宽度跟随侧栏。

## 已知限制

- 只在 DSH 桌面端开着时计时与提醒。DSH 退出后本轮状态丢失（统计不丢）。
- 吐司会被 Windows 专注助手 / 勿扰压掉；面板不受影响。
- 面板不记忆展开/收起状态，刷新页面回到展开。
