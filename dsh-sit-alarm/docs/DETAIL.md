# 久坐提醒

坐 40 分钟、起来活动 5 分钟。计时在 DSH 宿主进程里跑，页面刷新、切换会话都不丢；到点弹 Windows 吐司，面板自动展开提示。

## 一轮的流程

| 时刻 | 发生什么 |
|---|---|
| 点「开始 40 分钟」 | 进入专注，面板显示倒计时 |
| 第 37 分钟 | 吐司提醒「快结束了，准备站起来」，面板自动展开并变色 |
| 第 40 分钟 | 自动进入 5 分钟休息，吐司提示站起来活动 |
| 第 45 分钟 | 休息结束，吐司提示「休息达标」；**不自动开始下一轮**，面板停在「开始下一轮」等你点 |

休息超过 5 分钟完全没问题：面板会一直停在「休息达标」，你想休 15 分钟就休 15 分钟，回来点一下才开始下一轮。

## 面板

窗口右下角浮动卡片，收起后是一个带倒计时的小圆片，点开恢复。

- 专注中：暂停 / 结束
- 暂停中：继续 / 结束
- 休息中：开始下一轮（手动提前结束休息）/ 提前结束休息
- 休息达标 / 未开始：开始下一轮

## 配置

配置存在 `~/.dsh/sit-alarm.json`，改完保存即生效（宿主监听文件改动，不用重启，也不用重开一轮）：

```json
{
  "workMinutes": 40,
  "warnMinutes": 3,
  "breakMinutes": 5,
  "sound": true
}
```

| 字段 | 默认 | 说明 |
|---|---|---|
| `workMinutes` | 40 | 一轮专注多少分钟 |
| `warnMinutes` | 3 | 结束前几分钟提醒（0 = 不提醒） |
| `breakMinutes` | 5 | 休息倒计时多少分钟 |
| `sound` | true | 吐司是否带提示音 |
| `autoStartOnLoad` | false | 只有自测用：插件加载时直接开一轮 |

让智能体改配置，直接说「把专注改成 50 分钟、提前 5 分钟提醒」就行，它写这个文件；新值对下一轮生效，正在跑的一轮只调整提醒点。

## 实现

- Host 半侧是状态机：`idle → working → break → breakDone`，`paused` 可以插在 working/break 上。所有时间点存绝对时间戳，只用一个 `setTimeout` 睡到下一个事件。
- 浏览器半侧每 2 秒通过 Connection 的 `/api` 精确路由（`/api/sit-alarm`）拉一次状态，用 `endsAt` 在本地插值，秒数是连续的。
- 通知用 PowerShell + WinRT 吐司，AUMID `com.deepseek.dsh`（DSH 开始菜单快捷方式注册的那个）。
- 面板注册在 `shell.overlay` 槽，固定右下角，不挡聊天输入。

## 已知限制

- 只在 DSH 桌面端开着时计时与提醒。DSH 退出后本轮状态丢失。
- 吐司会被 Windows 专注助手 / 勿扰压掉；面板不受影响。
- 面板不记忆展开/收起状态，刷新页面回到展开。
